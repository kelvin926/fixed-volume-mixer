# Application icon

Created with the built-in image generation tool, then packaged as a multi-resolution Windows ICO.

- PNG: original transparent artwork
- ICO: 16, 20, 24, 32, 40, 48, 64, 128, 256 pixels
- Embedded in the executable for Explorer, the application window, taskbar and notification-area icon

Prompt:

Use case: logo-brand. Asset type: a single production Windows desktop application icon for a persistent audio volume mixer. Create a refined, friendly, minimal app icon: a deep midnight-indigo rounded square tile with a subtle blue-to-violet gradient and three very bold vertical white audio fader rails, each with one broad pill-shaped slider knob at a different height; the middle knob is bright aqua and the other two are white. Straight-on flat view, crisp silhouette, restrained slight depth, generous optical spacing, excellent readability when reduced to 16x16 or 32x32 pixels. A single centered icon filling about 88 percent of the square image, equal margins. Outside the rounded square must be truly transparent. No text, no letters, no numbers, no border, no surrounding scene, no mockup, no watermark, no extra symbols. Output one square high-resolution icon.
