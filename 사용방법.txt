고정 볼륨 믹서

FixedVolumeMixer.exe를 실행하세요. 설치나 관리자 권한이 필요 없습니다.

- 한 번 감지한 앱은 소리가 끝나거나 앱이 종료돼도 목록에 남습니다.
- 슬라이더 또는 숫자 입력으로 0~100%를 0.1% 단위로 설정할 수 있습니다.
- 종료된 앱의 볼륨을 바꾸면 저장했다가 다음 오디오 세션이 생길 때 적용합니다.
- 소리를 재생하기 전 앱을 등록하려면 '앱 미리 추가'에서 실행 파일을 선택하세요.
- 기본 항목은 PowerShell / Codex 알림 1%, 휴대폰과 연결 1%입니다.
- 그 밖의 앱은 처음 발견한 현재 볼륨을 유지합니다.
- 현재 Windows 기본 출력 장치를 따라갑니다. 기본 장치가 바뀌면 저장한 앱 볼륨을 새 기본 장치에 적용합니다.
- X로 닫으면 트레이에 남아 계속 적용합니다. '완전히 종료'로 종료할 수 있습니다.
- 'Windows 시작 시 실행'은 원할 때 직접 체크하세요. 기본으로 활성화하지 않습니다.
- 설정은 %LOCALAPPDATA%\FixedVolumeMixer\settings.json에 자동 저장됩니다.

알아둘 점

이 프로그램의 목록을 유지하는 방식입니다. Windows 기본 믹서의 목록을 고정하는 기능은 아닙니다.
Windows Core Audio의 세션 생성 알림을 이용하고, 주기적인 확인도 함께 합니다.
세션 생성 직후 볼륨을 적용하므로 새로운 앱의 첫 소리 시작 부분까지 무조건 제한하는 기능은 아닙니다.
같은 실행 파일 이름의 소리는 한 항목으로 관리합니다. PowerShell 항목은 Codex뿐 아니라 powershell.exe가 내는 다른 소리에도 적용됩니다.
앱이 알림과 통화를 같은 오디오 세션으로 내보내면 둘의 볼륨이 함께 바뀝니다.
아직 한 번도 재생되지 않은 앱은 자동 발견할 수 없습니다. 미리 등록하거나 소리를 한 번 재생하세요.
프로그램이 종료된 동안에는 새 세션의 볼륨을 감시하지 않습니다. 이미 적용한 Windows 볼륨 설정은 남습니다.
다른 믹서에서 바꾼 볼륨도 이 프로그램이 감지하면 저장합니다.
